# 图标集

来自 `TanchiPanda/Word_Funny_Game` 的 `site-icon/`，已复制进本仓库并做两处归一：

- `stroke="white"` 改为 `stroke="currentColor"`，便于跟随现有色板（`--green` / `--muted`）着色；
- 统一保留 24×24 viewBox、`fill="none"`、2px 描边，与后台边栏尺寸一致。

用法：`<span class="ic"><svg ...>…</svg></span>`，颜色由 `.ic` 的 `color` 决定。`favicon.svg` 是本仓库按同一视觉语言重绘的 Drive 版图标（云盘 + 下箭头），未使用原项目“词”字标。
