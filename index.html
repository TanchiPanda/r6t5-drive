能做什么

面向个人与小团队的文件管理，存储层可替换，不锁定服务商。

🗂

目录树与文件管理

多级文件夹、上传、下载、重命名、移动与搜索；每个用户的根目录以本人邮箱明示，路径隔离，越权访问被拦截。

🔗

分享与权限

规划中的链接分享可设置有效期、提取码、下载次数与文件夹分享；访问记录可追溯。

⚡

秒传与去重

按内容哈希去重，同一文件重复上传直接复用已有对象，省流量也省空间（适配器能力到位后启用）。

♻️

回收站

删除先进回收站，默认保留 30 天，可恢复或彻底清除；管理端可见容量占用。

🔐

Supabase 账号登录

账号体系对接 Supabase Auth，service key 只保存在服务端，前端不接触管理凭证；会话以 httpOnly Cookie 维持。

🧩

配额与开放接口

按用户组限制空间、单文件大小与 7 天上传流量；上传、列表、回收站等接口按契约实现，方便接进自己的流程。

部署形态

同一套代码，从本机调试到容器化自托管。

Docker 自托管

docker compose up -d 起一个站点，数据落在本机 data/ 目录；每个站点独立数据卷与端口，可多实例并行。

本机直接运行

无需 Docker 时，npm install 后 node server/index.js 即可启动，适合开发与联调。

侧车扩展（规划）

可按需挂载离线下载（aria2 / qBittorrent）与 ONLYOFFICE 在线编辑侧车，compose 中已留注释开关。

和公共网盘的区别

不评判别的产品，只说清自己的取舍。

维度R6T5 Drive公共网盘
存储位置自己的磁盘 / S3 兼容存储 / 只读仓库服务商机房
账号体系Supabase Auth，可自管项目各自独立账号
限速与配额由自己按用户组配置按会员等级
数据导出数据卷直读，随时迁走受客户端限制
可自托管支持 Docker / 本机运行不支持
