A private network disk that can be deployed by yourself: put files on your own server, support multi-person use, online preview and sharing. You don't need to buy cloud services, and a Docker container can run.

- Online demonstration: https://r6t5-drive-preview.r6t5.dpdns.org

- Source code repository: https://github.com/TanchiPanda/r6t5-drive

- Detailed deployment instructions: [`docs/deploy.md`](docs/deploy.md)

## What can you do?

**Daily use**

- Upload, download, rename, move, delete files, support multiple selection batch operations

- Large files can be uploaded in pieces. If the line is broken in the middle, it can be continued to be transmitted, and there is no need to do it again.

- Watch pictures, videos, audio, text, Markdown and PDF online

- When opening Office documents, you can choose your own reader (built-in PDF.js, Google Docs, Microsoft 365, etc.). After selecting once, the same type of file will remember your choice.

- Generate sharing links: validity period, extraction code and download limit can be set

- Deleted files are advanced to the recycle bin, which can be restored during the retention period, and will be completely removed after expiration.

**Administrator**

- Create new users, change passwords, block accounts; allocate space size, single file upper limit and weekly upload traffic according to user groups

- Visitors can register their own accounts, or they can turn off the registration.

- Different directories in the same site can have different storage locations (see below)

- Operation records (audit logs) can be checked

## Start quickly

### Method 1: Docker (recommended)

```Bash

Cp.env.example.env

```

Open `.env`, at least replace `SESSION_SECRET` with a string of random characters (can be generated by `openssl rand -hex 32`), and then:

```Bash

Docker compose up -d

```

After starting, open `http://server address:5212` in the browser.

It can also be used directly under Windows PowerShell:

```Powershell

New-Item-ItemType Directory-Force-Path.\data|Out-Null

Docker run -d --name r6t5-drive -p 5212:5212 -v "${PWD}\data:/app/data" ghcr.io/tanchipanda/r6t5-dri Ve: latest

```

All data is stored in the `./data` directory. See [`docs/deploy.md`](docs/deploy.md) for backup and upgrade methods.

### Method 2: Run directly (no Docker)

Node.js 20 or later version is required:

```Bash

Npm install

Npm start

```

## The first time to use

1. After starting, the administrator password is automatically generated once by default, printed in the server log, and found and logged in; you can also specify it yourself in `ADMIN_PASSWORD` of `.env`.

Two. After logging in to the management background, follow the page prompts to complete it in order:

- Choose a storage location (local folder / S3 compatible storage / read-only GitHub repository)

- Build at least one user group and set a limit

- Fill in the site name and external access address

3. After everything is completed, ordinary users can log in with email registration or administrator account.

## Where does the file exist?

The content of the file is not necessarily placed locally. It can be selected in the background. Three types of storage can be mixed:

| Type | Can it be uploaded | Applicable scene |

|---|---|---|

| Local folder | Yes | The simplest is that the file is in the data directory of the server |

| S3 Compatible Storage | Can | Compatible with MinIO, Cloudflare R2, Alibaba Cloud OSS, Tencent Cloud COS, Huawei Cloud OBS, etc. |

| GitHub repository | can only be downloaded | Hang up the files in the public repository for people to see |

The administrator can specify a directory (or a user) to a certain type of storage; read-only storage cannot be uploaded, renamed or deleted.

> When opening external readers such as Google Docs and Microsoft 365 online, the site needs to have an address that can be accessed on the public network, and the file link will only be valid for a short time (10 minutes).

## Frequently Asked Questions

** Will the data be lost? ** All the content is in your own `./data` directory, and you can back up this directory regularly. For details, please refer to the deployment document.

**Where are the files in the recycling station? ** The default reservation is 30 days (can be modified in `TRASH_RETENTION_DAYS` of `.env`), and it will be automatically deleted completely when it expires.

**How to upgrade? ** Restart the container after pulling the new mirror image. The data directory does not move, and the database will automatically update the structure.
